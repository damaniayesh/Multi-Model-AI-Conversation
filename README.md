# Multi-Model-AI-Conversation
A Python project that connects different AI models and allows them to answer questions and communicate with one another.

## Objective
To understand how different AI models work, compare their responses, and build conversations between multiple models.

## Steps Followed
1. Imported Python libraries and configured API keys.
2. Connected to different AI models using their APIs.
3. Tested the models with questions and reasoning tasks.
4. Connected a local Llama model using Ollama.
5. Compared the responses generated by different models.
6. Created a conversation where one AI model responds to another.
7. Extended the conversation to three AI models.
8. Tested how the models respond using shared conversation history.

## Outcome
Built a multi-model conversation system that demonstrates how different AI models can exchange messages and generate responses.
